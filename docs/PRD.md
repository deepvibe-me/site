# deepvibe PRD (초안)

> 이 문서는 `deepvibe-me/site` 레포의 현재 파일(`index.html` 등)만 보고 거꾸로 정리한 초안이다.
> 페이지에 적힌 내용은 **[확인]**, 페이지에서 미루어 짐작한 내용은 **[추정]**, 정해야 할 것은 **[결정 필요]**로 표시한다.

## 1. 개요
- **제품명:** 딥바이브 (deepvibe) — 도메인 `deepvibe.me` [확인]
- **한 줄 정의:** AI가 관계의 결을 읽어, 지금 만나는 사람과 더 잘 지내게 돕고 아직 없다면 결이 맞는 사람을 소개하는 서비스 [확인]
- **현재 단계:** 오픈 준비 중. 사전 알림 대기자를 모으는 랜딩 페이지만 운영한다 [확인]

## 2. 문제와 기회 [추정]
- 연애·썸 관계에서 "지금 뭘 해야 하지?"를 객관적으로 알기 어렵다.
- 카카오톡 대화에는 관계의 패턴이 이미 쌓여 있지만, 혼자 해석하기는 어렵다.
- 소개팅·매칭 서비스는 프로필 위주라 실제 대화 성향(결)은 반영하지 못한다.

## 3. 타깃 사용자 [확인 → 세부는 추정]
| 상태 | 사용자가 얻는 것 |
|---|---|
| 사귀는 중 | 무엇부터 바꾸면 되는지 |
| 썸 타는 중 | 다음에 뭘 하면 되는지 |
| 혼자 | 결이 맞는 사람 소개 |

주 사용층은 카카오톡을 주로 쓰는 한국 20~30대로 추정한다.

## 4. 핵심 기능

### 4.1 입력 데이터 [확인]
- **카카오톡 대화 (기본):** 대화 내보내기 파일 하나로 분석한다.
- **유튜브 · 구글 캘린더 (선택):** 동의 한 번으로 연결해 나를 더 입체적으로 읽는다.

### 4.2 분석 결과 [추정]
- **관계 리포트 (사귀는 중):** 대화 패턴, 갈등 지점, 우선 개선할 행동
- **다음 행동 가이드 (썸):** 관계 진행 단계 판단과 다음 행동 제안
- **나의 결 프로필 (공통):** 대화·관심사·생활 패턴에서 뽑은 성향

### 4.3 매칭 (혼자) [추정]
- 결 프로필이 비슷하거나 서로 맞는 사람을 소개한다.
- 매칭 방식, 상호 동의 절차, 노출 범위 [결정 필요]

### 4.4 사전 등록 (현재 구현됨) [확인]
- "오픈 알림 받기" 버튼 → 카카오톡 채널(`pf.kakao.com/_yxgVrX`) 친구 추가
- 혜택: 오픈 전 친구 추가 시 **이용권** 지급
- SNS: Instagram, TikTok, YouTube

## 5. 개인정보와 신뢰
- **분석이 끝나면 원본은 바로 지운다** [확인] — 핵심 약속이므로 기술적으로 보장해야 한다.
- 대화 상대방(제3자) 정보 처리에 대한 동의·고지 방식 [결정 필요]
- 분석 결과(파생 데이터)의 보관 기간과 삭제 방법 [결정 필요]
- 구글(유튜브·캘린더) OAuth 권한 범위는 최소로 한다 [추정]
- 개인정보처리방침·이용약관 페이지 필요 (현재 없음) [확인]

## 6. 사용자 흐름 (안) [추정]
1. 랜딩 → 카카오 채널 친구 추가 (현재 여기까지)
2. 오픈 알림 수신 → 가입 (카카오 로그인)
3. 관계 상태 선택 (사귀는 중 / 썸 / 혼자)
4. 카톡 대화 파일 업로드 (+ 선택: 구글 연결)
5. 분석 → 원본 삭제 → 결과 확인
6. (혼자) 매칭 제안 확인

## 7. 비즈니스 모델 [추정]
- "이용권" 단위 과금 (분석 또는 매칭 1회 소모)
- 사전 등록자에게 무료 이용권 지급
- 가격, 이용권 종류 [결정 필요]

## 8. 성공 지표 [추정]
- **사전 단계:** 카카오 채널 친구 수, 랜딩 방문 대비 전환율, SNS 유입 비중
- **오픈 후:** 업로드 완료율, 결과 만족도, 재분석·유료 전환율, 매칭 수락률

## 9. 디자인 원칙 [확인]
- 모바일 우선, 최대 폭 440px
- 색: 베이지 배경 `#f6f4f1`, 핑크 `#ff6f91`, 바이올렛 `#b967ff`, 카카오 노랑
- 폰트: Pretendard(본문), Fraunces(세리프 포인트)
- 색과 로고의 정본은 별도 앱 레포(`web/app/globals.css`, `docs/brand`)에 있고, 이 레포는 복사본을 쓴다
